ClearFrame

How your privacy works

Your photos are read and cleaned in this browser. Choosing a photo does not upload it. There is no account, and ClearFrame does not send your photos to a server.

What gets downloaded

This website does download its own page, scripts, styles, and fonts. That is how the tool reaches you. Those files are served by this site. They are not loaded from Google Fonts, a public script CDN, or another company’s servers.

JPEG, PNG, WebP, and GIF are cleaned with the scripts that load with the page. HEIC, HEIF, AVIF, TIFF, and RAW (DNG, CR2, NEF, and ARW) also need a photo engine of about 25 MB. The first time you add one of those files, the browser downloads vendor/exiftool/zeroperl-mqcadjqm.wasm from this same website. That download is the engine, not your photo. ZIP files are packed in the browser by a copy of JSZip that also ships with this site. Your browser then saves the download. Nothing is uploaded to create it.

What this page does not do

It does not run analytics or ads. Its own scripts do not set cookies. It does not embed third-party scripts, fonts, or images.

What the host can still see

Opening this site connects to the host that serves it (currently Vercel, at this site’s own address). Like other websites, that connection can include your IP address and the page address you requested. Your photos are not part of those requests. This page cannot turn host logs off. Those settings live outside this project’s files.

How to check

  1. Open your browser’s developer tools and choose the Network tab.
  2. Reload this page. The requests should go only to this site’s address. You should not see fonts.googleapis.com, fonts.gstatic.com, cdn.jsdelivr.net, or other sites.
  3. Add a photo on the home page and download a cleaned copy. You should not see an upload of the photo. For HEIC, HEIF, AVIF, TIFF, or RAW, the first use can download the photo engine named above from this site. Your photo is not in that request.
  4. This site does not install a service worker. After a page is open, cleaning uses what has already loaded. Reloading while offline will fail, because the browser has to fetch the page again. Working offline is not a feature of this version.

Limits

Cleaning removes metadata this scanner can find and that you select. It does not remove what is visible in the picture, watermarks, or data hidden in pixels. RAW files keep camera maker notes and rendering data, which can still identify a camera. File names and your device’s file dates are separate from metadata inside the photo. Scanning a cleaned copy shows what this tool can still read. It is not proof that every hidden detail is gone.

The privacy policy restates this for the site as a whole. Questions go to the contact page.
